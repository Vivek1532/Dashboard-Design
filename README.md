📊 Data Analyst Internship – Task 4
🧾 Task Title:
Dashboard Design using Power BI

🎯 Objective
The objective of this task was to design an interactive business dashboard for stakeholders using a Sales Financial dataset. The dashboard aims to provide meaningful insights that support data-driven decision-making.

🛠 Tools & Technologies Used
Microsoft Power BI
Superstore Sales Dataset (Kaggle)
Data Modeling & DAX Measures
📂 Dataset Used
Superstore Dataset (Sales Financial Data)

The dataset includes:

Order Date
Sales
Profit
Quantity
Category
Region
Customer Details
📊 What I Implemented in This Task
✅ KPI Cards (Summary Section)
Total Sales
Total Profit
Total Quantity Sold
Profit Margin
These KPIs provide a quick overview of overall business performance.

✅ Time-Series Analysis
Sales Trend Over Time (Line Chart)
Helps analyze business growth and seasonal patterns.
✅ Category Analysis
Profit by Category (Clustered Column Chart)
Identifies high and low performing product categories.
✅ Regional Analysis
Sales by Region (Clustered Bar Chart)
Shows geographical performance comparison.
✅ Interactivity
Added slicers for:

Category
Region
Order Date
All visuals dynamically update based on user selections.

✅ Dashboard Design Improvements
Clean and structured layout
Consistent color theme
Proper titles and formatting
Business-friendly visualization style
📈 Key Business Insights
Technology category generates strong profits.
Certain categories show lower profit margins.
Some regions contribute higher total sales.
Overall sales trend shows growth over time.
